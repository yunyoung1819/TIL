## :seedling: 섹션 5. [실습] Ollama 설치하기: Hugging Face란 무엇일까?: GGUF

### Hugging Face란 무엇일까?
- Hugging Face는 AI의 Github라고 생각하면 됨
- 소스코드를 공유할때 Github를 사용하는 것처럼 전세계의 AI 연구자들과 기업들이 자신들이 만든 AI 모델과 데이터를 무료로 올려두고 공유하는 세계 최대의 오픈소스 플랫폼

### GGUF
- GGUF는 GPT-Generated Unified Format
- AI가 최적화된 압축 파일 확장자
- 거대한 AI 모델들을 개인용 PC에서도 돌릴 수 있도록 압축(양자화)해놓은 파일
- Ollama는 GGUF를 돌려주는 구동기라고 생각하면 됨
