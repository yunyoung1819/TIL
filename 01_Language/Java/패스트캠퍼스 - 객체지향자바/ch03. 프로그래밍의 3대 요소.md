변수 선언: 메모리에 기억 공간

할당

### 01. 변수(V), 자료형(D), 할당(A)이란
프로그래밍의 3대 요소
- 변수 (Variable)
- 자료형 (Data type)
- 할당 (Assign)

변수 선언 -> 기억 공간이 만들어진다.

### 변수, 자료형, 할당 이해하기
- 변수(V): 데이터를 저장하는 메모리 공간의 이름 (symbol)
- 자료형(D): 변수의 크기와 어떤 종류의 데이터를 저장할 것인지를 결정하는 것 
  - int
    - 크기: 4 byte
    - 종류: 정수
- 할당(A): 변수에 데이터를 저장하는 것

변수의 이름을 짓는 방법
- 변수의 이름은 숫자로 시작할 수 없다.
- 대소문자가 구분되며 길이에 제한이 없다.
- $와 _ 이외의 특수문자는 사용할 수 없다
- 키워드(예약어)는 변수 이름으로 사용할 수 없다. ex) int, double, if, for, class ~

변수의 종류
- 멤버변수 (인스턴스 변수 = instance variable)
- 클래스변수 (스태틱 변수 = static variable)
- 지역변수 (local variable)
- 매개변수 (parameter, argument)

변수를 만들때 고려되는 것: 크기와 데이터 종류
- 자료형(DataType)
  - 어느 정도의 크기로 만들 것인가?
  - 변수에 어떤 종류의 데이터를 넣을 것인가?
- 자료형의 종류를 알아야 한다.
  - int, float, char, boolean ~: 기본 자료형
  - Book, Movie, Member ~: 사용자 정의 자료형

변수를 만들려면 (메모리에 기억공간을 만들려면?): 선언(declaration)을 해야한다.
- 선언하는 방법을 알아야한다
- 선언: 자료형과 변수가 만나야 한다.

> int a;
> float b;
> 

### 자료형의 종류를 알아보자
- 기본자료형 (Primitive Data Type): 프로그램에서 기본적으로 제공해주는 자료형
- 사용자 정의 자료형 (User Define Data Type): 사용자가 만들어서 사용하는 자료형

기본 자료형의 종류
byte: 1byte, 정수, 0
short: 2byte, 정수, 0
int: 4byte, 정수, 0
long: 8byte, 정수, 0L
float: 4byte, 실수, 0.0f
double: 8byte, 실수, 0.0d
char: 2byte, 문자, \u0000, null (널)
boolean: 1byte, 참거짓, false

사용자 정의 자료형 (객체자료형): 개발자가 만들어서 사용하는 자료형
문자열: String
